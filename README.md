# HR Workforce Dashboard | Power BI

## Project Overview
This project involves the development of an interactive Human Resources (HR) Workforce Dashboard using Microsoft Power BI. The dashboard presents workforce information in a visual format to support the analysis of employee demographics, departmental distribution, salary information, and performance.

## Objectives
- Analyse employee demographics and workforce distribution.
- Compare workforce numbers across departments.
- Explore salary distribution and salary-related information.
- Monitor employee performance scores.
- Present HR information through interactive visualisations to support data-driven decision-making.

## Tools and Technologies
- **Microsoft Power BI** – dashboard development and data visualisation.
- **Power Query** – data cleaning and preparation, where applicable.
- **DAX** – calculations and measures, where applicable.

## Dashboard Features
The dashboard includes visualisations and measures relating to:
- Employee demographics, including gender and age.
- Employee distribution across departments.
- Salary distribution and summary statistics.
- Employee performance scores.
- Interactive filters for exploring workforce information.

## Skills Demonstrated
- Data preparation and cleaning
- Exploratory data analysis
- Data visualisation
- Dashboard design
- HR workforce analysis
- Communicating insights through data

## Project File
The Power BI dashboard file (`.pbix`) is available in this repository and can be downloaded and opened using Microsoft Power BI Desktop.
